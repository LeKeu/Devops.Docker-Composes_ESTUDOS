# COMO USAR

### Ter o docker desktop já configurado na máquina!!
(caso não tenha, seguir: https://www.youtube.com/watch?v=qrvx6ivyrQw (ou algum outro tutorial de preferência))


### Abrir o TERMINAL a pasta em que o arquivo docker-compose se encontra
botão direito e "Abrir no Terminal"


### Para iniciar, rodar o comando:
docker compose up -d


### Para parar, rodar o comando:
docker compose down


#### Acessar UI pelo -> http://localhost:16686
#### Apontar o código para o Collector -> http://localhost:4317
